# Workbench 1.0.3-beta.2

**Update and restart** downloads the right Beta, verifies it, saves your latest
layout and unsent prompt, installs, and reopens Workbench on Windows and macOS.
Normal unsigned Beta installations can update automatically. A failed download,
save, or handoff keeps the app open; verified downloads remain ready for retry.

This Beta includes the updated Workbench views and tools:

- **Focus:** review project progress, milestones, and images attached to reports.
- **Services:** save local server commands by project, start and stop them, and
  read recent output. Services stop when Workbench quits; starting with the app
  is optional.
- **File controls:** open a generated file, save a copy, reveal its folder, or
  drag it into another app. Explicitly shown previews keep their place.
- **Permissions:** review agent access from the visible navigation entry.
- **Long conversations:** recent responses and transcript exports read a bounded
  part of the transcript instead of loading the entire file.

Older builds that still say **Show installer** need to run this installer once
to receive the new updater. An already patched local build can use its Update
button. Active Windows agent connections that use Workbench’s executable must
finish before replacement; the updater reports this without terminating them.
macOS automatic replacement supports a writable Applications installation.
Signed applications retain publisher validation, and operating-system controls
remain in effect.

Download the package for your computer from the
[GitHub Beta release](https://github.com/keeganarko/workbench-classic/releases/tag/v1.0.3-beta.2).
See the [update guide](../updater-design.md) for installation details.
