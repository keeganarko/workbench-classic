# Workbench 1.0.2-beta.1

Keep track of the work across your projects, then open the conversation or
result when you want a closer look.

- **See the whole project in Focus.** Project previews, task illustrations,
  reported milestones, and a Needs you filter make it easier to find the next
  useful action. Agent reports remain labeled; a finished turn is not proof
  that an entire task is complete.
- **Coordinate from one place.** An explicitly granted App Manager can work
  across projects while workers stay in their own folders. Existing Project
  Manager permissions remain limited to their project.
- **Move between overview and detail.** Open a worker's terminal, read a
  progress update, or preview its latest document without losing the project.
- **Keep an eye on usage.** Claude and OpenAI usage readings refresh from
  available account data and identify stale readings.

Installers are provided for macOS 13+ on Apple silicon and Intel, and Windows
10 build 19041+ on Intel/AMD and ARM64. Windows uses Ubuntu on WSL 2 for the
coding agents; see the [Windows setup guide](../windows-native-prototype-setup.md).

In an updater-enabled Beta, choose **Updates → Check for updates → Download
update → Show installer**. Finish active agent sessions, quit Workbench, and
run the verified download. Projects and preferences remain outside the app.
These Beta installers are unsigned and may require operating system
confirmation; automatic restart installation requires matching distribution
signatures. Builds without Updates need a manual installation first.

This release publishes a Beta update manifest for all four supported targets.
The app checks at startup, periodically while open, and when you click Check
for updates. Source pushes alone do not publish an installer.
