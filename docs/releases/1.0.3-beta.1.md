# Workbench 1.0.3-beta.1

Windows updates now finish inside Workbench: click **Update** to download,
verify, save your workspace, install quietly, and reopen. If an active agent
connection or a failed save postpones the restart, the download stays ready
for a retry.

- **Background services:** save local server and shell commands by project,
  start or stop them from Services, and inspect their status and recent output.
  Services stop when Workbench quits; starting with the app is optional.
- **File controls:** open generated files, save a copy, reveal their folder,
  or drag the file into another application from the preview. Files and folders
  also have a separate Open action in the Files tree.
- **Reliable previews:** explicitly shown documents keep their place, and slow
  renders or files produced by another conversation no longer replace them.
- **Focus progress images:** reports can include a screenshot, diagram, or
  illustration made for that update. Workbench saves a copy with the report,
  and the board shows projects with live sessions.
- **Clearer permissions:** a visible Permissions entry opens the existing
  agent access controls; project and app-wide grants retain their boundaries.
- **Long conversations:** reading the latest response and exporting a recent
  transcript now reads from the end of the file, avoiding loading the entire
  conversation into memory. Build temporary files also use disk-backed storage.

Project files, settings, layouts, and conversation records stay outside the
application being replaced. Finish active agent sessions before installing.
Older Windows builds that still show **Show installer** need one manual
installation to receive the updater fix. These unsigned Mac packages use the
manual installer; automatic Mac updates require signed builds. Windows or macOS
may ask for confirmation when installing an unsigned Beta.

Download the package matching your operating system and processor from the
[GitHub release](https://github.com/keeganarko/workbench-classic/releases/tag/v1.0.3-beta.1).
See the [setup guide](../guide.md) and [update guide](../updater-design.md)
for prerequisites and platform details.
