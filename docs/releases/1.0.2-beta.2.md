# Workbench 1.0.2-beta.2

This draft was superseded before publication by [1.0.3-beta.2](1.0.3-beta.2.md).

**Update and restart now installs the update and reopens Workbench.** You no
longer need to find and run a downloaded installer for a normal Beta update.

- One click downloads the right Mac or Windows package, verifies it, saves the
  latest layout and unsent prompt, installs, and relaunches Workbench.
- Unsigned Beta installations can update to the next verified unsigned Beta.
  Signed installations keep their publisher checks; a changed signing identity
  requires an explicit manual installation.
- A failed download or save keeps the app open. If installation fails after
  shutdown, the helper attempts to reopen Workbench and reports the error on
  the next launch.
- Project Focus, central coordination, preview outputs, recurring tasks, and
  refreshed usage readings from Beta 1 remain included.

**First update:** 1.0.2-beta.1 and earlier updater-enabled builds still use
Download update → Show installer. Run this new installer once to get the new
Update and restart button. A published release cannot change code in an older
app before that code is installed.

Windows agent connections that are still using Workbench's executable must
finish before replacement; the updater reports this instead of terminating
them. Ordinary tmux terminals retain their existing reconnect behavior.
macOS automatic replacement supports Workbench installed in Applications or
in your personal Applications folder with write access. System policy or an
unusual installation location may still require a manual installer.
