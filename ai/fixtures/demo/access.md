# Atlas — sample access policy

This is invented demonstration content, dedicated to CC0.

A project owner selects the folders that the local index may read. Hidden files, credential files, dependency folders, generated outputs, and symbolic links are excluded. The index is stored in the user's cache, outside the project repository.

Every document result includes its source file and line number. If the source changes after indexing, the old citation is excluded until the index is rebuilt. A retrieval score is a ranking signal and must not be presented as answer confidence.

A guest at the demonstration sees only the included sample records. No project source files are uploaded by the demonstration. Public distribution needs the project owner's decision.

If a question has no supporting source, the presenter should say that the evidence is missing. A plausible guess must not be substituted for a citation.
