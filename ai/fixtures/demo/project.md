# Atlas — sample project brief

This is invented demonstration content, dedicated to CC0. It contains no customer or company records.

Atlas turns uploaded research documents into a searchable project library. The prototype runs on a developer's computer. Its owner is Mina and its reviewer is Sol.

The first milestone is a cited search result: the user asks a question, opens a source passage, and can verify where it came from. Success means finding the correct source in the first five results.

The pilot budget allows existing hardware and free software. A public website, a paid model endpoint, and a paid subscription require a later decision. The prototype does not publish uploaded documents.

The pilot sequence is intake, retrieval, review, and a small demonstration. The date for inviting external testers has not been set.
